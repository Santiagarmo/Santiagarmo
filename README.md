## About me

I'm a full-stack developer and QA engineer working in a government in-house software factory on a Moodle-based learning platform with hundreds of thousands of users. I pair end-to-end delivery (backend services, web-service plugins, Vue interfaces) with automated testing, web accessibility, data engineering and applied AI.

- 🧪 QA: pytest, vitest, Playwright, black-box security testing
- ♿ Web accessibility (WCAG) and reproducible bug reports
- 📊 Data pipelines and analytics on PostgreSQL
- 🤖 Applied AI: computer vision (MediaPipe) and local LLMs

## Featured project

### [AutoConciliador](https://github.com/Santiagarmo/autoconciliador)
B2B automatic bank reconciliation for WhatsApp e-commerce: matches payments declared by sales advisors against official bank statements to release orders.
**Stack:** FastAPI · PostgreSQL · SQLAlchemy 2 / Alembic · Vue 3 · Docker Compose · Clean Architecture
